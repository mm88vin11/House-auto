# 🏡 House-auto — продажа дома в одну кнопку

Автоматическая публикация объявления о продаже дома (Шахтёрск, ул. Капустина) в Telegram-чаты,
свой Telegram-канал, группы ВКонтакте, плюс сайт-визитка дома и «пульт» с готовыми текстами
для досок объявлений.

```
           house.yaml  ──►  4 варианта текста  ──►  Telegram-чаты     (от вашего аккаунта)
       (данные о доме)       full / medium /    ──►  ваш TG-канал      (от вашего бота)
           photos/           short / plain      ──►  группы ВК         (от вашего аккаунта)
                                    │           ──►  доски ДНР, ОК     (пульт: «Копировать» → вставить)
                                    └──────────────►  сайт дома на GitHub Pages (все фото, план, кнопка «Позвонить»)
```

## 📦 Приложение (самый простой путь)

**Скачать:** [для Windows](https://github.com/mm88vin11/House-auto/raw/app/HouseAuto-Windows.zip) · [для Mac](https://github.com/mm88vin11/House-auto/raw/app/HouseAuto-Mac.zip). Распакуйте, запустите
`HouseAuto`, откроется окно в браузере: вход в Telegram прямо там (номер → код), кнопка
«🚀 Опубликовать везде сейчас», автопилот, переключатели площадок, цена, сайт и тексты.
Ключи хранятся только на вашем компьютере (папка `HouseAuto-data`), GitHub-секреты не нужны.
Без сборки: `pip install -r requirements.txt && python run_app.py`.

## Облачный режим (без компьютера)

**Одна кнопка:** GitHub → вкладка **Actions** → **🏡 Опубликовать объявление** → **Run workflow**.
Кроме того, публикация **сама запускается каждый день в 10:17 по Москве** и постит только туда,
где подошёл срок по правилам этой площадки.

## Что умеет

| | |
|---|---|
| ✍️ **Тексты** | Один источник — `house.yaml`. Сменили цену — все тексты, сайт и будущие посты обновились. Четыре формата под лимиты площадок: полный, для подписи к фото в Telegram (≤1024), короткий (≤500), без эмодзи для досок. |
| 📸 **Фото** | Альбом до 10 фото в Telegram и ВК. Первое фото — обложка, `plan.jpg` всегда последним. |
| ⏱ **Расписание по правилам чата** | Для каждой площадки: не чаще раза в N дней, только в разрешённые дни недели, тема форума. |
| ♻️ **Без мусора** | Перед новым постом бот удаляет свой прошлый в этом чате — объявление «поднимается», а не копится. Админы такое терпят, дубли — банят. |
| 🛡 **Защита аккаунта** | Паузы 45–120 с между постами, лимит постов за запуск, автостоп платформы при флуд-контроле, капче или ограничении от Telegram. |
| 🔎 **Поиск площадок** | `discover` ищет чаты и группы по ключевым словам (Шахтёрск, Торез, Енакиево, Донецк, ДНР недвижимость…) и складывает в `candidates/`. ВК — только те группы, куда можно писать или предлагать новость. |
| 🌐 **Сайт дома** | Красивая страница с галереей, коммуникациями, садом, картой и кнопками «Позвонить» / «Написать». Ссылку на неё ставим во все объявления — фото не теряются при пересылке. |
| 🧾 **Отчёт** | После каждого запуска — отчёт в личку от вашего бота: где опубликовано (со ссылками), где ошибка, кто ждёт очереди. |
| 🧹 **Дом продан** | Режим «Снять все объявления» удаляет все живые посты одной кнопкой. |

## Настройка (один раз, ~30–40 минут)

Все пароли и ключи хранятся в **секретах GitHub**: репозиторий → **Settings → Secrets and variables →
Actions → New repository secret**. В файлы их не вписывайте.

### Шаг 1. Фото и данные
1. Загрузите фото в папку `photos/`: `01.jpg`, `02.jpg`, … Первое — самое выигрышное (дом с улицы,
   солнечный день). Обязательно: фасад, каждая комната, веранда, сад, постройки, улица. План — `plan.jpg`.
2. Проверьте `house.yaml`. **Очень советую указать цену** — объявления с ценой получают в разы
   больше откликов, а во многих чатах без цены пост удаляют.

### Шаг 2. Сайт дома
1. Репозиторий должен быть публичным (бесплатный GitHub Pages работает только для публичных).
2. **Settings → Pages → Source: GitHub Actions.**
3. **Actions → 🌐 Сайт дома → Run workflow.** Через минуту сайт будет по адресу
   `https://<ваш-логин>.github.io/House-auto/`.
4. Впишите этот адрес в `site_url` в `house.yaml` — ссылка появится во всех объявлениях,
   а в Telegram/ВК при пересылке подтянется превью с обложкой.

### Шаг 3. Свой Telegram-канал + бот (отчёты и витрина)
1. В Telegram создайте канал, например «Продаётся дом · Шахтёрск, Капустина», с публичной ссылкой.
2. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен → секрет **`TG_BOT_TOKEN`**.
3. Добавьте бота в канал администратором с правом публикации.
4. В `targets.yaml` в `my_tg_channel` впишите `@адрес_канала` и `enabled: true`.
5. Для отчётов: напишите своему боту `/start`, узнайте свой id у [@userinfobot](https://t.me/userinfobot)
   → секрет **`TG_OWNER_CHAT_ID`**.

### Шаг 4. Публикация в Telegram-чаты (от вашего аккаунта)
Бот в чужие чаты писать не может, поэтому используем ваш аккаунт.
1. Зайдите на [my.telegram.org](https://my.telegram.org) → **API development tools** → создайте
   приложение → получите `api_id` и `api_hash` → секреты **`TG_API_ID`**, **`TG_API_HASH`**.
2. На любом компьютере с Python (или в GitHub Codespaces: **Code → Codespaces → Create**) выполните:
   ```bash
   pip install -r requirements.txt
   python -m house_auto login
   ```
   Введите номер телефона и код из Telegram. Скопируйте выведенную длинную строку → секрет **`TG_SESSION`**.
   ⚠️ Эта строка = полный доступ к аккаунту. Никому не показывайте, никуда, кроме секрета GitHub, не вставляйте.

### Шаг 5. ВКонтакте
Нужен токен пользователя с правами `wall, photos, groups, offline`:
1. [dev.vk.com](https://dev.vk.com) → **Мои приложения → Создать** (тип Standalone / «Веб» в VK ID).
2. Откройте в браузере (подставьте ID приложения):
   ```
   https://oauth.vk.com/authorize?client_id=ID_ПРИЛОЖЕНИЯ&scope=wall,photos,groups,offline&response_type=token&redirect_uri=https://oauth.vk.com/blank.html&v=5.199
   ```
3. Разрешите доступ, из адресной строки скопируйте значение после `access_token=` (до `&`) → секрет **`VK_TOKEN`**.

*Если ВК поменял порядок выдачи токенов — актуальная инструкция на dev.vk.com, раздел «Получение ключа доступа пользователя».*

### Шаг 6. Найти площадки
1. **Actions → 🏡 Опубликовать объявление → Run workflow → «Найти новые чаты и группы».**
2. В репозитории появятся `candidates/telegram.yaml` и `candidates/vk.yaml` — отсортированы по числу участников.
3. По каждому кандидату: откройте чат, **прочитайте закреп/правила**. Подходит — перенесите запись
   в `targets.yaml`, поставьте `enabled: true` и задайте `days` / `min_interval_days` по правилам.
   Чужие **каналы** попадают в список как `manual` — там пишите админу о размещении (часто платно,
   зато охват тысячи человек; для дома это стоит своих денег).
4. Добавьте вручную то, что знаете сами: чаты вашего района, соседних городов, «барахолки», группы ОК.

### Шаг 7. Запуск
1. **Пробный запуск** — покажет, что и куда уйдёт, ничего не отправляя.
2. **Опубликовать везде прямо сейчас** — первая волна.
3. Дальше всё идёт само каждый день по расписанию каждой площадки. Отчёт приходит в Telegram.
4. Доски объявлений ДНР (dnr.red, КупиПродай, Доски.ру, Domick, Копеечка) и группа «Шахтёрск»
   в Одноклассниках — **вручную, один раз**: откройте `out/kit.html` (скачивается в Actions →
   запуск → Artifacts → `pult-kit`), нажмите «Копировать», вставьте, отметьте галочку.
   У этих сайтов нет API, а объявление на них живёт неделями.

## Правила, чтобы не забанили

- **Начните с 10–15 чатов**, через несколько дней добавляйте ещё. Новый аккаунт, который в первый же
  день пишет в 50 чатов, Telegram ограничит.
- **Только там, где объявления разрешены.** Нарушили правила — удалят и забанят, а остальные участники
  запомнят вас как спамера.
- **Интервал — минимум 3–4 дня** для одного чата, если правила не требуют другого.
- Если пришёл отчёт «Telegram ограничил аккаунт (PeerFlood)» — сутки ничего не трогайте, потом уменьшите
  число чатов и увеличьте `min_interval_days`.

## Команды (для компьютера)

```bash
python -m house_auto texts              # показать все тексты
python -m house_auto site               # собрать сайт (_site/) и пульт (out/kit.html)
python -m house_auto publish --dry-run  # пробный запуск
python -m house_auto publish            # опубликовать, где пора
python -m house_auto publish --force --only tg_xxx vk_yyy   # прямо сейчас, только в эти
python -m house_auto status             # где висят объявления, когда следующие
python -m house_auto discover           # найти новые площадки
python -m house_auto remove             # снять все объявления
python -m unittest                      # тесты
```

## Устройство

```
house.yaml               данные о доме
targets.yaml             площадки и их правила
photos/                  фото
state/posts.json         журнал: что, где, когда опубликовано (сохраняется автоматически)
candidates/              найденные площадки на проверку
house_auto/
  texts.py               4 варианта текста
  site.py                сайт дома + пульт
  scheduler.py           кому пора публиковать
  publish.py             запуск, удаление старых постов, паузы, отчёт
  discover.py            поиск чатов и групп
  posters/               отправка: telegram_user, telegram_bot, vk
.github/workflows/       кнопка публикации + сайт
```
